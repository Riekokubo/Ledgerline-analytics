# GAS 版のセットアップと使い方

Ledgerline Analytics を Google Apps Script（GAS）で配信し、集計に必要な項目だけを
Google スプレッドシートに保存して使うための手順です。
公開デモ（GitHub Pages）はこれまでどおり架空データで動き、何も保存しません。

## しくみ

```
ブラウザ（いつもの画面）
  │ CSV はブラウザで読み込み、氏名・住所・メールなどはここで破棄
  │ 集計用の7項目だけを送る
  ▼
GAS（gas/Code.js）… 暗証番号とトークンを確認してから読み書き
  ▼
スプレッドシート
  ├ orders            注文（注文番号・注文日・合計・返金・キャンセル・購入タイプ・紹介者）
  ├ goaffpro_monthly  GoAffPro の月別データ
  └ meta              最終取り込みの記録
```

- 同じ注文番号を取り込み直すと、新しい内容で上書きします（あとから返金・キャンセルされた注文も反映されます）。
- GoAffPro の **月別（Annual Report）は保存** します。**紹介者別（Leaderboard）は保存しません**（期間ごとに貼り付けて確認する使い方のため）。

## 最初の1回だけ

### 1. スプレッドシートと GAS を用意する

1. Google ドライブで新しいスプレッドシートを作る（例：「Ledgerline データ」）。
2. メニューの「拡張機能 › Apps Script」を開く。
3. 左の「プロジェクトの設定（歯車）」を開き、次の2つを行う。
   - 「スクリプト ID」をコピーしておく。
   - 一番下の「スクリプト プロパティ」で、プロパティ `PIN`、値に暗証番号を入れて保存する。
     英数字8文字以上、または覚えやすい合言葉にする。

### 2. 手元のプロジェクトから GAS に送る

1. https://script.google.com/home/usersettings を開き、「Google Apps Script API」をオンにする。
2. ターミナルで clasp にログインする（ブラウザが開くので、スプレッドシートを作ったアカウントで許可する）。
   ```
   npx @google/clasp login
   ```
3. `gas/.clasp.json.example` をコピーして `gas/.clasp.json` を作り、`scriptId` にコピーしたスクリプト ID を入れる。
   （このファイルは Git に入らない設定です）
4. ビルドして送る。
   ```
   npm run push:gas
   ```
   `gas/` の中の `Code.js`・`index.html`・`appsscript.json` が GAS に送られます。

### 3. ウェブアプリとして公開する

1. Apps Script の画面で「デプロイ › 新しいデプロイ」を開く。
2. 種類は「ウェブアプリ」。
   - 次のユーザーとして実行：**自分**
   - アクセスできるユーザー：**全員**
3. 「デプロイ」を押し、権限の確認画面で許可する。
4. 表示された「ウェブアプリの URL」を、興梠さん・社員の方に共有する。暗証番号は別の手段（電話や口頭など）で伝える。

> 「全員」にしても、暗証番号がないとデータは見られません。
> 暗証番号の確認・データの読み書きはすべて GAS 側で行い、5回続けて間違えると15分ロックされます。

## 毎月の使い方（先月分を入れる）

1. Shopify 管理画面 › 注文管理 › エクスポート で、先月分の注文を CSV で書き出す。
2. ウェブアプリを開いてログインし、「データ取り込み」で CSV を読み込む。
   緑の「〇件の注文をスプレッドシートに保存しました。」が出れば完了です。
3. （任意）GoAffPro › Analytics › Annual Report の表をコピーして貼り付け、「照合データとして取り込む」。
4. 「ダッシュボード」で「先月」を選ぶ。

## 更新したとき

コードを直したら、次の2つを行います。URL は変わりません。

1. `npm run push:gas`
2. Apps Script の「デプロイ › デプロイを管理 › 編集（鉛筆）› バージョン：新バージョン › デプロイ」

## よくある操作

| やりたいこと | 方法 |
| --- | --- |
| 暗証番号を変える | プロジェクトの設定 › スクリプト プロパティ の `PIN` を書き換える（コードの変更は不要） |
| 間違ったデータを消す | スプレッドシートの `orders` シートで、その行を削除する |
| 全部やり直す | `orders`・`goaffpro_monthly`・`meta` の見出し以外の行を削除する |
| 別のスプレッドシートを使う | スクリプト プロパティ `SPREADSHEET_ID` にそのスプレッドシートの ID を入れる |

## 開発メモ

- `npm run build:gas`：`vite build --mode gas` で JS・CSS を1つの HTML に埋め込み、`gas/index.html` を作る。
- GAS の画面は iframe の中で動くため、GAS 版だけ `MemoryRouter`（URL を使わないルーター）にしている。
- `gas/Code.js` のテストは `src/lib/gas/server.test.ts`。GAS の機能をまねた偽物の上で、実際の Code.js を動かして確かめている。
